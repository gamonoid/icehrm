⚠️ IceHrm now updates itself. When a newer release is published, administrators see a banner on the dashboard — click **Update** and the updater downloads it, backs up your current version, and replaces the program files. No terminal, and one-click rollback if anything goes wrong.

More information about the upgrade process can be found [here](https://icehrm.com/explore/docs/upgrade-icehrm/).

-------

### ☘️ New Features

#### A Completely New Interface
* IceHrm now runs as a single-page application — the shell stays loaded, so moving between modules is instant instead of a full page reload.
* Persistent application shell: the sidebar and header never reload, only the content area changes.
* **Areas**: modules grouped into People, Time and Work, Leave and Pay, switchable from the top of the sidebar, so long menus stay manageable.
* **Global module search**: type in the header search box to jump straight to any module you have access to.
* Permission-aware menu — the sidebar shows only what the signed-in user may open.
* Deep links: every module has its own address, so screens can be bookmarked and shared.

#### Dark Mode
* A full dark theme across the entire application, remembered per browser.
* Applied before the first paint, so there is no white flash on load.
* Charts, dialogs, tables and forms are all themed.

#### Works on a Phone
* The sidebar collapses into a drawer, cards stack, and tables become scrollable.
* Employees can check leave balances and submit requests from a phone browser.

#### In-App Notifications
* Approvals, assignments and reminders appear in a notification tray in the header, with an unread count, rather than relying solely on email.

#### Redesigned Dashboards
* **Organization Overview** for administrators: employees, departments and pending approvals as clickable cards that navigate to the underlying module.
* Headcount growth, gender diversity, employment type and headcount by department charts.
* **Employee Dashboard**: leave balances, upcoming holidays, pending requests, assigned tasks and training on one personal home page.

#### Leave Management
* New leave module in the open source edition: leave types, leave period, work week, public holidays and manual leave adjustments.
* Employees apply for leave and see entitlement, pending and approved requests in one place; managers approve or reject from the same screen.
* **Leave Calendar** lays the whole team's absences across the month, so clashes are obvious before anything is approved.
* Leave data now shown on timesheets.

#### Visual Company Structure
* Company structure list with type, reporting line, address, country, timezone and headcount, plus inline edit, duplicate and delete.
* New **Org Chart** tab rendering the same data as a proper hierarchy.
* Employee-facing **Company** view presents the same structure to staff.

#### Modernised Everyday Screens
* Rebuilt as native React views — no more embedded frames, consistent styling, and dialogs that match the rest of the application.
* **Employee Directory**: searchable directory of colleagues with photos, roles and contact details.
* **Time Sheets**: weekly entry and review with project breakdowns and an approval flow.
* **Employee Profile**: personal details, qualifications, dependents, emergency contacts and documents organised into tabs.

#### Extensions Marketplace
* Browse and manage the extensions available to your installation from inside the application, with licence status for each one.
* Purchases are now kept current automatically instead of only refreshing when the marketplace page is opened.

#### Built-in Updater
* **What's New** opens the changelog for your edition.
* The updater downloads the release, checks the version, and asks you to confirm before anything is replaced.
* Your data is kept — configuration, uploads and cached files are never replaced.
* Extensions you installed yourself are preserved and reported back to you.
* Automatic backup: the previous version is moved aside before new files are copied in.
* One-click rollback if the application does not come back, and a full log of every step.

### 💼 Improvements

* Material-style theme with Roboto typography throughout, replacing the previous default serif font.
* Consistent card layouts, spacing and iconography across every module.
* Themed dialogs and forms, including on the older screens.
* Charts restyled and made readable in both light and dark themes.
* Clickable KPI cards that navigate to the underlying module.
* Bundled public-holiday import for the Holidays tab.
* Module descriptions throughout the Manage Modules screen.
* Employee profile photos shown consistently in lists, charts and headers.
* Database migrations now run automatically the next time any user signs in — no separate step, and the migration runs exactly once even if several people sign in at once.
* Production Docker setup updated; MySQL is now published on loopback only.

### 🐛 Bug Fixes

* Fixed the overtime report.
* Fixed the employee leave list name.
* Fixed marketplace module issues.
* Migration fixes and Docker container tweaks.

### 🗑️ Removed

* Legacy UI removed — every screen now runs in the new application shell.

### 📋 Upgrade Notes

* **Requirements**: no change. IceHrm v36 runs on the same PHP and MySQL versions as v35.
* **Breaking changes**: none. All changes are backward compatible.
* **Extensions**: existing installations continue to work unchanged; extensions you installed yourself are preserved across updates.
